# Engineering decisions

- This is **not** an actual vehicle diagnostic service; all values are invented and static.
- Synthetic boundaries: `battery_voltage < 11.0` means `LOW_VOLTAGE`; `battery_temperature > 60.0` means `HIGH_TEMPERATURE`.
- Exact 11.0 V and 60.0 °C are both normal *for these synthetic checks*.
- If both warning conditions occur, include both alerts, in stable voltage-before-temperature order; aggregate status is `WARNING`.
- If a sensor is unavailable or its measurement is `None`, return `INVALID_DATA`; malformed values like strings, booleans and infinity raise `InvalidSampleError`.
- Sensor readings are fixed to make tests repeatable. No real Tesla data, alarms, protocol, real service connection, or safety claim.
- Dashboard reads actual JUnit XML generated by running pytest. Missing reports must not be displayed as a fabricated PASS.
- ML is a separate optional experiment and cannot replace explicit diagnostic rules.
